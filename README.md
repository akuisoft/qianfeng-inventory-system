# 前锋电器进销存管理系统 · 模块功能可视化介绍

面向集团多组织（工厂 + 经销商 + 分销商）的厨卫电器行业进销存与渠道经营平台介绍页。
覆盖采购、销售、库存、服务、返利、财务与渠道态势感知全链路，支持 SN 全生命周期追溯与 T+21 智能预测。

## 在线查看

直接用浏览器打开 `index.html` 即可（纯静态单页，无任何外部依赖，可离线查看）。

如果已开启 GitHub Pages，访问地址为：

```
https://akuisoft.github.io/qianfeng-inventory-system/
```

## 页面内容

| 区块 | 说明 |
| --- | --- |
| 系统总体架构 | 接入层 / 网关与安全 / 业务服务层 / 数据层 / 运行环境 |
| 九大业务模块 | 系统管理、基础资料、采购管理、销售管理、库存管理、服务管理、财务与返利、渠道态势感知、移动采集端 |
| 核心业务流程 | 采购三级审核 + 返利兑现、SN 全生命周期追溯、经销商评估、态势感知 + 智能决策 |
| 技术栈 | Spring Boot 3.2、MyBatis-Plus、MySQL 8 + Redis、JWT + Security、Vue 3 + Element Plus、ECharts 离线地图、uni-app、Docker + Nginx |
| 角色权限 | 11 种角色 RBAC，组织树行级隔离 + 字段级脱敏 |

## 关键指标

- 9 大业务功能模块
- 11 种角色 RBAC 权限
- 44 张数据库业务表
- 4 级行政区划下钻（省 → 市 → 区县 → 乡镇街道）
- 私有化部署，数据不出内网
